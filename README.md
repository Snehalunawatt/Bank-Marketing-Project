
Bank Marketing Project

Data Science | Python | Machine Learning

📌 Project Overview

This project focuses on analyzing bank marketing campaign data and applying Machine Learning techniques to understand customer behavior and improve marketing campaign effectiveness.

🎯 Project Objectives

- Analyze bank marketing campaign data.
- Perform Exploratory Data Analysis (EDA).
- Understand customer characteristics and behavior.
- Apply data preprocessing and feature engineering.
- Build and evaluate Machine Learning models.

📊 Dataset

- Dataset: Bank Marketing Dataset
- File: "bank-additional-full.xls"
- Format: Excel

🛠️ Technologies & Libraries Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

🔍 Project Workflow

1. Data Loading
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Feature Engineering
6. Machine Learning Model Development
7. Model Evaluation

📁 Project Files

- "Bank Marketing Project.ipynb" – Jupyter Notebook containing project code and analysis.
- "Bank Marketing Project Documentation.docx" – Project documentation.
- "bank-additional-full.xls" – Dataset file.

🚀 How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook.
4. Run the notebook cells sequentially.
